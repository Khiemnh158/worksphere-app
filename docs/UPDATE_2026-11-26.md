# Bản cập nhật mã nguồn ngày 26/11/2026

## Thay đổi

- Thay springdoc 2.6.0 bằng 3.1.1 để sửa lỗi HTTP 500 của `/v3/api-docs` trên
  Spring Boot 4.1.1. Giữ mục tiêu Java 21.
- Bổ sung OpenApiConfig mô tả JWT bearer và các thao tác auth công khai.
  SecurityConfig và service tiếp tục quyết định quyền truy cập.
- Bước đăng nhập API/Android nhận mật khẩu hiện có không rỗng, tối đa 128 ký tự,
  rồi chuyển đến kiểm tra mật khẩu trên máy chủ. Không áp quy tắc tạo mật khẩu
  mới vào việc đăng nhập tài khoản đã tồn tại. Chính sách kích hoạt, reset và đổi
  mật khẩu không được nới trong bản này; không đặt mật khẩu chung trong source.
- React Native Gradle plugin được resolve bằng `toRealPath()` trước khi import
  để xử lý Windows junction khi Gradle Sync. Cần chạy `npm ci` trước khi mở Android.
- Nginx chuyển các đường Swagger và OpenAPI về API trong Docker để dùng cùng
  origin với web. Chỉ chuyển các đường tài liệu này, không mở cổng management.

## Kiểm chứng trước khi đẩy mã

- Checkout bàn giao riêng: Maven package bằng JDK 21 đạt 20 test, không failure,
  error hoặc skip. Gồm OpenApiPostgresTest, LoginRequestValidationTest,
  AttendanceRulesTest, TaskWorkflowTest và TwoFactorServiceTest. PostgreSQL dùng
  database thử riêng.
- Hai suite Android authValidation/LoginScreen đạt 36 test; `tsc --noEmit` đạt.
- Web đạt 8 test phiên và phân trang.
- `nginx -t` đạt với Nginx 1.28.0 Windows từ nguồn chính thức. Qua proxy thử riêng,
  Swagger UI/config/schema trả 200 và API nghiệp vụ khi chưa đăng nhập trả 401.
  Harness chỉ đổi listener thành cổng loopback tạm và upstream sang API local;
  cấu hình Docker vẫn giữ `api:8080`. Chưa thay kiểm tra Linux container.
- Trước đó cùng ngày, Gradle help/IDE Sync và Run localDemo x86_64 đã thành công
  trên máy thực hành. Bản cập nhật source không kèm cache, APK hoặc đường dẫn JDK máy tác giả.
- Lượt Swagger local trước đó có 17 test tập trung, 56 kiểm tra môi trường riêng
  và 45 kiểm tra sau cập nhật. Đây là các tập kiểm chứng khác nhau, không cộng
  thành một tổng test của toàn bộ sản phẩm.

Docker engine đang tắt trong lượt bàn giao mã. Chưa build lại image hoặc chạy
Jenkins/Sonar cho commit này; tuyến Nginx mới cần qua kiểm tra Docker/CI.
Kết quả Jenkins #10 ngày 25/11 vẫn thuộc commit `2ae3b83`.

## Chạy và đối chiếu

Local: [hướng dẫn clone và chạy](FRESH_CLONE_RUNNING.md), Swagger ở cổng API:
`http://127.0.0.1:18120/swagger-ui/index.html` theo cấu hình mặc định.

Docker: repo [worksphere-deployment](https://github.com/Khiemnh158/worksphere-deployment)
ghim commit app trong `versions.env`; cần cập nhật checkout app và build lại
thì container mới nhận bản sửa. Không dùng việc push GitHub làm bằng chứng rằng
container đang chạy đã được cập nhật.
